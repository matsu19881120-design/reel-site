プライバシーポリシー

最終更新日：2026年10月6日

本ポリシーは、YouTubeチャンネル「リールの裏側」の運営者（以下「運営者」）が使用する動画投稿ツール「shorts-auto」（以下「本ツール」）における情報の取り扱いについて定めるものです。

1. 本ツールの目的

本ツールは、運営者自身のYouTubeチャンネルに、運営者が作成した動画を自動でアップロードするためだけに使用します。運営者以外の利用者向けのサービスではありません。

2. 取得する情報

本ツールは、Googleアカウントの認証（OAuth）により、YouTube Data APIの「動画のアップロード」の権限（https://www.googleapis.com/auth/youtube.upload）のみを使用します。運営者以外の第三者の個人情報は取得しません。

3. 情報の利用方法

取得した認証情報は、運営者のチャンネルへの動画のアップロード、およびサムネイル画像の設定のためだけに使用します。

4. 情報の保存と管理

認証情報は、アクセスが制限された非公開の環境（GitHubの暗号化されたSecrets）にのみ保存し、適切に管理します。

5. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。

6. Google API サービスの利用について

本ツールによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

7. 権限の取り消し

本ツールに付与した権限は、Googleアカウントの権限設定からいつでも取り消すことができます。

8. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更後の内容は本ページに掲載した時点で有効となります。

Privacy Policy (English)

The tool "shorts-auto" is used only by the owner of the YouTube channel "リールの裏側" to upload the owner's own videos to the owner's own channel. It uses only the YouTube Data API scope https://www.googleapis.com/auth/youtube.upload. No personal data of third parties is collected. Credentials are stored only in encrypted, access-restricted GitHub Secrets and are never sold, shared or transferred to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
